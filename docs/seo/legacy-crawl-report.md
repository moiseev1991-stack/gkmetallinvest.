# Отчёт о краулинге gkmetallinvest.ru

Дата: 2026-04-02. Метод: HTTP-запросы к публичным URL и `robots.txt`. Полный `sitemap.xml` с сервера вернул **500** — индексировать программно не удалось; список ниже основан на проверенных вручную страницах и ссылках с главной.

## Результаты проверки URL из ТЗ

| URL | Статус | Наблюдение |
|-----|--------|------------|
| `/` | OK | Главная, каталог, услуги, формы |
| `/all` | OK | Широкая коммерческая «Поставка нержавеющего металлопроката» |

| `/lenta` | OK | **Отдельная** посадочная: лента/штрипс, производство из рулона, прецизионные сплавы (не дублирует `/catalog/lenta`) |

## Дополнительные обнаруженные URL (для будущего mapping)

- `/provolokanerzh` — нержавеющая проволока (ссылка с главной).
- `/contacts` — в `robots.txt` в Disallow; страница контактов может индексироваться иначе — уточнить при полном краулинге.
- Tilda-служебные: `/policy`, `/publicoffer`, страницы `page*.html` — при миграции решить судьбу каждой (301 на новые политики или 410).

## Рекомендации

1. После восстановления sitemap — полный краулинг (Screaming Frog / wget) и дополнение [redirects-301.csv](redirects-301.csv).
2. В Search Console сверить топ-URL и добавить их в CSV приоритетом.
3. Старая `/lenta` и `/catalog/lenta` — **две сущности**; на новом сайте: `/lenta/` (каталог) + `/lenta/proizvodstvo/` (производство/штрипс) с перекрёстными ссылками.
