# Гайд по копирайтингу для gkmetallinvest.ru

> База знаний для seo-copywriter агента. Глоссарий, стиль, типовые ошибки, LSI-словарь.
> Обновляется по мере того, как находим новые типовые косяки или новые тематические кластеры.

## 1. Аудитория и тон

**Кто читает:** закупщик / снабженец / инженер-конструктор / технолог / прораб. Профессионал, который ищет конкретику. Знает разницу между AISI 304 и 316L и не нуждается в объяснении, что такое нержавейка.

**Чего хочет:**
- Понять, есть ли нужная марка/размер в наличии
- Узнать цену и условия (тонна, розница, доставка)
- Свериться с ГОСТом, аналогом, составом
- Получить КП быстро

**Тон:** деловой, без панибратства, без академического занудства. Как переписка снабженца с менеджером.

## 2. Канон стиля

### Чёрный список (никогда не пиши)

| Фраза | Почему запрещена |
|---|---|
| «индивидуальный подход» | штамп нулевой информативности |
| «гибкие условия» | штамп |
| «качественный продукт» | штамп |
| «лидер рынка» | необоснованное утверждение |
| «команда профессионалов» | штамп |
| «многолетний опыт» | штамп, повторяется на 90 % B2B-сайтов |
| «свяжитесь с нами», «обращайтесь» | в конце каждого абзаца — выглядит как реклама |
| «в современных условиях» | вводная вода |
| «как известно» | вводная вода |
| «следует отметить» | вводная вода |
| «уникальный», «непревзойдённый», «инновационный» | громкие прилагательные |
| «!!!», «)))» | эмоция в B2B-тексте |
| Эмодзи | не для официальных страниц сайта |
| «у нас вы можете» | разговорный оборот |
| «надёжный поставщик» | штамп; покажи цифрами, а не словами |

### Белый список (так писать хорошо)

- **Числа и допуски:** «0,4–50 мм», «±0,5 %», «1–7 дней», «от 0,1 т».
- **Технический фактаж:** «титан связывает углерод в карбиды TiC», «питтинговая стойкость растёт с увеличением Mo».
- **Прямые ответы:** в FAQ первое предложение — ответ. Без разгона.
- **Активный залог:** «отгружаем в день оплаты», а не «отгрузка осуществляется».
- **Конкретные ссылки на стандарты:** «ГОСТ 9941-81», «ASTM A312», «EN 10088-2».
- **Внутренние ссылки** на смежные хабы и марочные.

### Длина предложений

- Цель: 12-18 слов в среднем.
- Один длинный период до 25 слов допустим, если в нём есть инфо.
- Конструкции типа «является», «осуществляется», «производится» — заменяй на активные глаголы.

### Длина абзацев

- 2-5 предложений (40-90 слов).
- Длинный список — выноси в `<ul>`.

## 3. LSI-словарь по теме

Используй разные слова для одной сущности. Поисковик понимает синонимы — это снижает плотность главного ключа и расширяет охват.

### Нержавейка → синонимы

- нержавейка
- нержавеющая сталь
- нержавеющий металлопрокат
- коррозионно-стойкая сталь
- сталь нержавеющая (для канцеляризованных контекстов — ГОСТ)
- inox / инокс (международный термин, особенно для дизайна/архитектуры)

### Купить → синонимы

- купить
- заказать
- приобрести (редко, для разнообразия)
- поставка (для тендерных контекстов)
- отгрузка (для логистики)

### Цена → синонимы

- цена
- стоимость
- прайс
- прайс-лист
- расчёт КП

### Производитель / продавец → синонимы

- поставщик
- металлобаза
- металлоторговая компания
- металлотрейдер

### Город — варианты предложного

- Москва / в Москве
- Санкт-Петербург / в Санкт-Петербурге / СПб / в СПб
- Нижний Новгород / в Нижнем Новгороде
- Екатеринбург / в Екатеринбурге
(в данных `src/data/cities.ts` — все формы)

## 4. Терминология (расширенный глоссарий)

### Типы коррозии

- **Атмосферная** — стандартная, влажный воздух
- **Питтинговая** — точечные язвы в хлоридах (морская вода, реагенты)
- **Щелевая** — в зазорах, под отложениями
- **МКК (межкристаллитная)** — по границам зёрен после сварки/нагрева 450-850 °C
- **Контактная** — при контакте с углеродистой сталью

### Поверхности (детальнее)

| Код | Что | Применение |
|---|---|---|
| 1D | горячекатаный, отжиг, травление | строительство, без эстетики |
| 2B | холоднокатаный, отжиг, травление, прокатка | базовая, ёмкости, оборудование |
| 2D | то же что 2B, но без финишной прокатки | для последующей обработки |
| BA (2BA) | холоднокатаный, отжиг в защитной атмосфере | декор, бытовая техника |
| 4N / №4 | шлифовка зерном 180-240 | архитектура, кухни |
| №6 | сатин зерном 240-320 | декор |
| №7 | полировка зерном 600+ | декор, отражатели |
| №8 / mirror | зеркальная | декор, медицина |
| PE / PVC | защитная плёнка | для перевозки, монтажа |

### Сертификация

- **Сертификат завода** — паспорт качества с плавкой и анализом
- **3.1 (EN 10204)** — европейский сертификат с указанием химсостава и механики плавки
- **3.2** — то же + проверка независимой третьей стороной

## 5. Структурные шаблоны страниц

### Шаблон: хаб каталога (например, /list/, /truba/)

```
H1: Лист нержавеющий
Лид (60-100 слов): что есть в наличии, диапазоны размеров, марки, склад НН.

H2: Толщины и форматы листа [LSI: размерные хвосты]
  60-100 слов + список основных размеров (1, 1.5, 2, 3, 4, 6, 10 мм)

H2: Поверхности листа [LSI: 2B, BA, шлифованный, зеркальный]
  60-100 слов + таблица или список

H2: Марки нержавейки в наличии [LSI: AISI 304/316L/321/430]
  60-80 слов + ссылки на марочные посадочные

H2: Доставка по России [LSI: гео-кластер]
  60-80 слов + сроки по топ-городам, ссылки на гео

H2: Документы и сертификация
  60-80 слов

FAQ (6-8 вопросов)
  закрывает информационные ключи кластера
```

### Шаблон: справочная страница (например, /gost/)

```
H1: ГОСТы для нержавеющего металлопроката — справочник
Лид (60-80 слов): что внутри, как пользоваться, ссылки на хабы.

H2 по каждому ГОСТу:
  Каждый = 100-150 слов

### Шаблон: гео-страница (например, /list/v-moskve/)

```

Прайс-таблица

H2: Доставка в Москву — сроки и способы
H2: Самовывоз из Нижнего Новгорода

### Шаблон: статья (блог-пост) (например, /blog/magnitit-li-nerzhaveika/)

```
H1: точная формулировка запроса пользователя
Лид (40-60 слов): прямой ответ на главный вопрос

H2: ... (под каждый аспект)
  100-200 слов на раздел

Заключение / TL;DR (40-60 слов)
Внутренние ссылки на марочные и хабы

JSON-LD: Article + потенциально FAQPage
```

## 6. Типовые ошибки в текущих текстах сайта

Сюда складываем то, что находим в ревью существующих страниц.

- [ ] Title карточки товара не содержит размер первым числом — стоит проверить ProductDetail.astro
- [ ] На главной не хватает упоминания «inox / инокс» (665 точных)
- [ ] /list/aisi-316l/ не упоминает «AISI 316» как близкий вариант (963 точных уходят мимо)
- [ ] /truba/ нет явного H2 «бесшовная vs электросварная vs профильная» (~1100 точных)
- [ ] /detali-truboprovoda/ всё в одном блоке вместо разделения по типам (отводы / фланцы / тройники)
