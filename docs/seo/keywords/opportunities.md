## 4. ГОСТы — отдельный кластер

Запросы вида «гост 9941», «гост 5582», «гост 7350» с **высокими частотами** (693-1920 точных!). Это золото — пользователь ищет конкретный ГОСТ, чтобы свериться. Идея: страница-справочник `/gost/` с расшифровкой каждого ГОСТа + ссылкой на хаб, который этим ГОСТом регулируется.
