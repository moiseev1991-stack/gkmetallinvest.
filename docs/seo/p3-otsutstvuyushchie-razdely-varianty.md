# Отсутствующие разделы (п.3 блиц-аудита) — варианты решения

Документ для обсуждения/уточнения. Составлен 30.07.2026 по данным репозитория
(`src/data/pricelist.json`, `updatedAt: 2026-05-12`) и карте ключей
`docs/seo/keywords/keyword-map.csv` (Wordstat, 472 ключа, «точная» частота — по
оператору `"!"`).

Ситуация: на сайте есть спрос без посадочных страниц. Случаи принципиально
разные — в одном товар уже лежит в прайсе, в другом товара нет вообще.

---

## Случай A. Лестничные ограждения — товар есть, раздела нет

### Факты

В хабе `/detali-truboprovoda/` (758 позиций) лежит две несвязанные группы:

| Группа | Позиций | Что внутри |
|---|---:|---|
| **Ограждения и лестничные комплектующие** | **~476** | лестничные элементы 240, отводы поручня 55, наконечники 49, заглушки поручня 39, декоративный низ 35, стеклодержатели 22, пристенный крепёж 14, держатели ригеля 7, крепления стоек 7, настенные фланцы 8 (принадлежность уточнить) |
| Собственно детали трубопровода | ~292 | фланцы плоские 78 и воротниковые 75, переходы 61, отводы 41, клапаны 18, тройники 12, задвижки 7 |

То есть большинство раздела — ограждения, а называется он «Детали
трубопровода». Аудитории разные: ограждения покупают монтажники и
строители-отделочники, детали трубопровода — снабженцы и монтаж инженерных
систем.

Спрос по Wordstat (точная частота, /мес): «ограждения из нержавейки» — 129,
«перила нержавеющие» — 56, «нержавеющие перила» — 25. Итого ~210 в узком ядре
плюс хвост (стойки, ригели, стеклодержатели, поручень 50,8 — в выгрузку не
попали, так как выгрузка делалась по слову «нержавейка/нержавеющий»).
В карте ключей эти запросы уже помечены целевым URL `/lestnichnye-ograzhdeniya/`,
которого не существует.

Побочный эффект склейки: заголовки. Карточки ограждений одного диаметра
получали одинаковый `<title>` («Лестничные элементы 50,8 мм AISI 304» — 47 раз),
потому что title собирался из «подкатегория + размер + марка», а название
изделия (отвод поручня / седловина / заглушка / держатель под стекло) в него не
попадало. Это правится отдельно и уже сделано.

### Вариант A1 — посадочная-разрез, карточки на месте (рекомендуемый)

**Что делаем.** Новая страница `/lestnichnye-ograzhdeniya/`: свой H1, текст,
фото, чипы по типам элементов (поручень, стойки, ригели, стеклодержатели,
крепёж, заглушки, наконечники) и прайс-таблица, отфильтрованная по этим
подтипам. URL карточек товара остаются прежними —
`/detali-truboprovoda/<slug>/`. В меню — отдельный пункт «Лестничные
ограждения».

- Редиректов не нужно: ни один существующий URL не меняется.
- Работы: 1 страница + запись в навигации + текст (~800–1000 слов).
- Риск: карточки формально остаются в «чужом» разделе — хлебные крошки товара
  ведут в «Детали трубопровода». Лечится подменой крошки по подтипу (полдня).

**Плюсы:** быстро, ничего не ломается, вся семантика закрывается посадочной,
которая и должна ранжироваться по «ограждения/перила из нержавейки».
**Минусы:** структура каталога остаётся не совсем логичной; при росте
ассортимента придётся всё равно делать вариант A2.

### Вариант A2 — полноценный вынос в отдельный хаб

**Что делаем.** Новый хаб `/lestnichnye-ograzhdeniya/` по образцу прайсовых
хабов: хаб + карточки товара `[slug]` + марочные посадочные + гео-страницы
`v-[city]`. Позиции ограждений переносятся из `detali-truboprovoda` в отдельный
хаб в данных, карточки получают новые URL
`/lestnichnye-ograzhdeniya/<slug>/`.

- Нужны 301-редиректы: ~476 URL (`vercel.json` / `public/_redirects`).
- Нужна переработка слагов: сейчас они вида `lestn-osnovnye-aisi-304-50-8mm-3`
  (то есть «подкатегория-марка-размер-номер»), для отдельного хаба логично
  сделать читаемые — `zaglushka-vneshnyaya-50-8-aisi-304`. Это ещё раз меняет
  URL, поэтому делать надо одним заходом.
- Работы: 3–5 дней с текстами, редиректами и проверкой перелинковки.
- Риск: временная просадка по перенесённым карточкам (обычная картина при 301
  на 400+ URL — 2–6 недель на переиндексацию). Сейчас риск минимален, потому
  что сайт ещё не в индексе (стоит глобальный `noindex`), — если делать вынос,
  то **до** снятия запрета на индексацию, тогда просадки не будет вовсе.

**Плюсы:** правильная структура, гео-страницы и марочные посадочные для
ограждений (это ещё ~20 URL под «ограждения из нержавейки в Москве» и т.п.),
чистые хлебные крошки, отдельный раздел в меню и в sitemap.
**Минусы:** объём работ и разовая переиндексация.

### Что нужно решить по случаю A

1. Ограждения — самостоятельное направление продаж или сопутствующий товар?
   Если самостоятельное — вариант A2, и лучше сделать его до выхода в индекс.
2. Настенные фланцы (8 позиций) — это крепление стойки ограждения или
   трубопроводная арматура?
3. Нужны ли гео-страницы по ограждениям (15 городов) — они дают ~20 URL, но
   контент там шаблонный.

## Случай B. Электроды, метизы, подшипники — спрос есть, товара нет

### Факты

| Раздел | Спрос exact/мес | Топ-запросы | Что в прайсе |
|---|---:|---|---|
| Электроды для нержавейки | 672 | электроды для нержавейки 354, электроды для сварки нержавейки 264, электроды нержавеющие 18 | нет |
| Метизы нержавеющие | 449 | саморезы нержавеющие 152, нержавеющая шпилька 70, болты нержавеющие 58, метизы нержавеющие 54 | нет |
| Подшипники нержавеющие | 49 | нержавеющие подшипники 22, подшипники нержавеющие 19 | нет |

Раньше по этим темам были страницы-заглушки, сейчас они удалены из навигации
совсем. В карте ключей целевые URL `/elektrody/`, `/metizy/`,
`/podshipniki/` указаны, но страниц нет — запросы не покрыты ничем.

Важно про конкурентную планку: в выдаче по «электроды для нержавейки» стоят
страницы с конкретными марками (ОЗЛ-8, ЦЛ-11, НЖ-13, ЭА-400/10У), диаметрами
2/3/4 мм, упаковками и ценами за кг. Страница без номенклатуры конкурировать с
ними не сможет — это надо принимать как данность при выборе варианта.

### Вариант B1 — страницы «под заказ» без прайса

**Что делаем.** Три страницы по образцу уже сделанного раздела трубопроводной
арматуры (`src/data/armatura.ts` + компонент `HubRequest`): текст, типовая
номенклатура списком (без цен и остатков), форма запроса, ссылки на смежные
разделы.

- Работы: ~1 день на все три (шаблон готов).
- Ожидаемый результат: сбор низкочастотных и брендовых запросов, немного
  заявок «а есть ли у вас…». В топ по «электроды для нержавейки» такая
  страница не выйдет.
- Риск: тонкие страницы без ассортимента — если их будет много, это ухудшает
  общее качество сайта в глазах поисковика. Три штуки на 4600 страниц — не
  проблема.

### Вариант B2 — полноценные разделы с номенклатурой

**Что делаем.** То же, что для прочих хабов: таблица позиций с фильтрами
(марка электрода / диаметр / упаковка; тип метиза / диаметр / длина / ГОСТ /
марка стали), карточки товара, марочные посадочные при необходимости.

- **Нужны данные от поставщика:** номенклатура в любом виде (Excel, PDF,
  ссылка на прайс). Минимум — обозначение, типоразмер, единица; желательно
  цена и наличие. Без цены можно, тогда «цена по запросу».
- Работы: 2–3 дня на раздел при наличии внятного прайса (парсер + страницы +
  тексты). Основное время съедает не код, а нормализация номенклатуры.
- Приоритет по спросу: электроды → метизы → подшипники. Подшипники (49) можно
  вообще не делать.

### Вариант B3 — не делать

Осознанно отказаться: сосредоточиться на п.2 (подтипы уже имеющегося
ассортимента — профильная труба, отводы, фланцы, квадрат, шестигранник), где
товар есть и суммарный спрос ~1800 запросов/мес. Электроды и метизы — это
другой товарный мир (сварочные материалы и крепёж), с другими поставщиками и
логистикой.

### Что нужно решить по случаю B

1. Есть ли доступ к номенклатуре электродов и метизов (хотя бы список без цен)?
2. Готовы ли реально продавать эти позиции (возить под заказ), или страницы
   нужны только для трафика? Если только для трафика — это заявки, которые
   некому исполнить.
3. По подшипникам: делать или закрыть тему?
