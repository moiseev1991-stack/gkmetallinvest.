## 4.2. Подробные карточки новых калькуляторов

### 1. Калькулятор веса арматуры

**Источник:** `/kalkulyator-vesa-metalloprokata/kalkulyator-vesa-armatury`
**Что считает:** масса стержня арматуры за заданную длину.
**Применение:** строители рассчитывают суммарный вес арматуры для армирования фундаментов, плит, колонн — это самый массовый запрос в металлопрокате.

#### Входы

| Поле | Единица | Тип | Дефолт | Диапазон / варианты | Примечание |
|---|---|---|---|---|---|
| Номинальный диаметр | мм | dropdown | 6 | 6, 8, 10, 12, 14, 16, 18, 20, 22, 25, 28, 32, 36 | По ГОСТ 5781-82 |
| Длина L | м | text input | 0 | > 0 | Можно дробное |

Кнопки режима: **Расчёт веса** / **Расчёт длины** (обратный расчёт: ввести нужный вес — получить длину).

#### Выходы

| Величина | Единица | Примечание |
|---|---|---|
| Вес | кг | Суммарный вес стержня |
| Площадь | м² | Условная — у источника показывает 0 м², видимо не реализовано |
| Средняя цена × масса | руб. | Опциональный маркетинговый блок |

#### Формула

Арматура — не простой цилиндр. Вес берётся из таблицы **ГОСТ 5781-82**, где для каждого номинального диаметра задан теоретический вес единицы длины m₁ в кг/м:

```
m = m₁ × L
```

Значения m₁ по ГОСТ 5781-82:

| d, мм | m₁, кг/м |
|---|---|
| 6 | 0.222 |
| 8 | 0.395 |
| 10 | 0.617 |
| 12 | 0.888 |
| 14 | 1.208 |
| 16 | 1.578 |
| 18 | 1.998 |
| 20 | 2.466 |
| 22 | 2.984 |
| 25 | 3.853 |
| 28 | 4.834 |
| 32 | 6.313 |
| 36 | 7.990 |

Значения учитывают поперечные рёбра (профиль арматуры классов А400 / А500С). Плотность стали 7 850 кг/м³ принята в расчёте ГОСТ, пользователь её не задаёт.

#### Численный пример

Входы: d = 10 мм, L = 1 м → **m = 0.617 кг** (источник: 0.616 кг).
Практика: 10 прутков d=12, L=6 м → m = 0.888 × 6 × 10 = **53.3 кг**.

#### Связь с нашим каталогом

Арматура у нас не продаётся (нержавеющая арматура — крайне узкая ниша). Рекомендуется **отдельная посадочная** `/kalkulyator-armatury/` для SEO-трафика с примечанием, что мы работаем с нержавеющим прокатом, и призывом к переходу в каталог.

#### Инфографика

**Тип:** ортогональная проекция, вид на торец — 2D схема сечения.

**Композиция:** квадратный кадр. В центре — круглое сечение арматурного стержня диаметром ~70% высоты холста. Осевые пунктирные линии крест-накрест делят круг на 4 квадранта. По бокам круга (на 3 и 9 часах) — два малых выступа (схематичные поперечные рёбра, D-образные «ушки» шириной ~3–4% диаметра).

**Размеры:** D — наружный диаметр: двусторонняя горизонтальная стрелка под кругом от края до края, подпись «D» в центре под стрелкой.

**Стиль линий:** контур круга — толстая линия (1.5–2 px). Рёбра — тонкий контур. Внутри сечения — диагональная штриховка 45° (левый наклон) с равным шагом. Осевые линии — тонкие пунктирные. Без 3D и градиентов.

**Цвета:** чёрно-белое. Контур чёрный, заливка — штриховка, фон белый/светло-серый.

**Подписи:** только латинская «D», шрифт sans-serif.

**Что менять при переносе:** контур `var(--color-primary)` (синий), стрелки `var(--color-accent)` (оранжевый), шрифт Inter. Добавить подпись «Арматура А500С / ГОСТ 5781-82» мелким текстом.

### 2. Калькулятор веса балки двутавровой

**Источник:** `/kalkulyator-vesa-metalloprokata/kalkulyator-vesa-balki-dvutavrovoy-dvutavra`
**Что считает:** масса двутавровой балки заданного типа и длины.
**Применение:** проектировщики металлоконструкций подбирают двутавр под нагрузку и считают вес металла для сметы.

#### Входы

| Поле | Единица | Тип | Дефолт | Варианты |
|---|---|---|---|---|
| Тип балки | — | dropdown | Нормальный двутавр (Б) | ГОСТ 8239-89; Б; Ш (широкополочный); К (колонный); Д (дополнительной серии); С (сварной) |
| Номер балки | — | dropdown | 10Б1 | Зависит от типа: для ГОСТ 8239-89 — 10, 12, 14…60; для Б — 10Б1…100Б4 (37 позиций) |
| Длина L | м | text input | 0 | > 0 |

Кнопки режима: **Расчёт веса** / **Расчёт длины**.

#### Выходы

| Величина | Единица |
|---|---|
| Вес | кг (= m₁ × L) |

#### Формула

```
m = m₁ × L
```

m₁ — линейный вес из ГОСТ 8239-89 (обычный двутавр) или ГОСТ 26020-83 (Б, Ш, К-серии).

Пример значений m₁ по ГОСТ 8239-89:

| 12 | 11.50 |
| 14 | 13.70 |
| 16 | 15.90 |
| 18 | 18.40 |
| 20 | 21.00 |
| 27 | 31.50 |
| 30 | 36.50 |
| 40 | 57.00 |

Пример значений Б-серии (ГОСТ 26020-83):

| Профиль | m₁, кг/м |
|---|---|
| 10Б1 | 8.10 |
| 20Б1 | 17.90 |
| 30Б1 | 28.00 |
| 40Б1 | 39.80 |

#### Численный пример

ГОСТ 8239-89, Номер 20, L = 1 м → **21.000 кг** (проверено).

#### Связь с каталогом

Двутавр у нас не продаётся. Та же модель, что и арматура: SEO-лендинг `/kalkulyator-balki/` с переходом к нашим трубам/уголкам как альтернативным несущим профилям.

#### Инфографика

**Тип:** 2D ортогональная проекция, разрез торца — схема поперечного сечения двутавра.

**Композиция:** горизонтальный кадр 4:3 или 3:2. В центре — I-образное сечение. Высота балки ~2/3 высоты рисунка. Стандартная ориентация: полки горизонтальны, стенка вертикально.

**Размеры (для 10Б1):**
- h = 100 мм (высота): вертикальная двусторонняя стрелка слева, подпись «100»
- b = 55 мм (ширина полки): горизонтальная стрелка под нижней полкой, подпись «55»
- tw = 4.1 мм (толщина стенки): горизонтальная стрелка по середине стенки, подпись «4.1»
- tf = 5.7 мм (толщина полки): вертикальная стрелка у правого края нижней полки, подпись «5.7»

**Стиль:** контур — толстая чёрная линия. Внутри — диагональная штриховка 45°. Переходы стенка-полка скруглены.

**Цвета:** чёрно-белое.

**Подписи:** только числа (100, 4.1, 5.7, 55), без буквенных обозначений.

**Что менять:** добавить обозначения h, b, t_w, t_f. Стрелки оранжевые, контур синий, шрифт Inter.

**Что считает:** масса стального швеллера по номеру профиля и длине.
**Применение:** строительные и промышленные конструкции — перемычки, каркасы, опорные элементы. Нержавеющий швеллер используется в пищевой промышленности, судостроении.

#### Инфографика

**Тип:** 2D ортогональная проекция, вид на торец П-образного профиля.

**Размеры (для 5П):**

- tw = 4.4 мм: стрелка внутрь стенки, подпись «4.4»

**Стиль:** контур толстый, штриховка 45°, углы переходов прямые или слабо скруглённые.

**Цвета:** чёрно-белое.

**Подписи:** числа без буквенных обозначений.

**Что менять:** добавить h, b, t_w. Наша палитра.

| Высота полки b | мм | text input | 0 | Вертикальная полка, может = a |
| Толщина t | мм | text input | 0 | Одинакова для обеих полок |
| Длина L | м | text input | 0 | > 0 |

Кнопки режима: **Расчёт веса** / **Расчёт длины**.

#### Формула

```
m = (a + b − t) × t × L × ρ / 1 000 000
```

При SI: a, b, t в мм; L в м; ρ в кг/м³; результат m в кг.

Расшифровка: (a + b − t) — суммарная длина средней линии сечения без двойного счёта угла; t — толщина полки; L — длина; ρ — плотность (7 850 для Ст3, 7 900 для аустенитной нержавейки, 7 700 для ферритной).

> Формула без учёта скруглений в углах. Для ГОСТ-значений применяются справочные таблицы с учётом наружных и внутренних галтелей.

#### Численный пример

Нержавейка 12Х18Н10Т (ρ = 7 900), a = 50, b = 32, t = 4, L = 1 м:
m = (50 + 32 − 4) × 4 × 1 × 7900 / 1 000 000 = 78 × 4 × 7900 / 1 000 000 = **2.465 кг/м** ✓ (проверено).

Ст3 (ρ = 7 850), те же размеры: 78 × 4 × 7850 / 1 000 000 = **2.450 кг/м** (источник: 2.434 — разница из-за галтелей).

#### Связь с каталогом

Добавить **режим «неравнополочный»** в существующий калькулятор уголка в `/kalkulyator-vesa/`: при a = b получается равнополочный, при a ≠ b — неравнополочный. Один калькулятор с двумя полями a и b вместо одного «полка».

#### Инфографика

**Тип:** 2D проекция сечения, вид на торец L-образного профиля.

**Композиция:** квадратный или слегка вертикальный кадр. Г-образная (зеркальная Г) фигура: вертикальная полка b слева, горизонтальная a внизу, угол в левом нижнем углу. Обе полки заштрихованы. Открытая сторона уголка — вправо и вверх.

**Размеры:**
- a — горизонтальная стрелка под нижней полкой, подпись «a»
- b — вертикальная стрелка левее вертикальной полки, подпись «b»
- t — стрелка поперёк стенки, подпись «t» справа

**Стиль:** контур толстый, штриховка 45°, без скруглений.

**Цвета:** чёрно-белое.

**Что менять:** показать наглядно a ≠ b разными цветами стрелок или подписью «неравнополочный». Наша палитра.
