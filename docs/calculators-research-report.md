## 4.2. Подробные карточки новых калькуляторов

### 1. Калькулятор веса арматуры

**Источник:** `/kalkulyator-vesa-metalloprokata/kalkulyator-vesa-armatury`
**Что считает:** масса стержня арматуры за заданную длину.
**Применение:** строители рассчитывают суммарный вес арматуры для армирования фундаментов, плит, колонн — это самый массовый запрос в металлопрокате.

#### Входы

| Поле | Единица | Тип | Дефолт | Диапазон / варианты | Примечание |
|---|---|---|---|---|---|
| Номинальный диаметр | мм | dropdown | 6 | 6, 8, 10, 12, 14, 16, 18, 20, 22, 25, 28, 32, 36 | По ГОСТ 5781-82 |
| Длина L | м | text input | 0 | > 0 | Можно дробное |

Кнопки режима: **Расчёт веса** / **Расчёт длины** (обратный расчёт: ввести нужный вес — получить длину).

#### Выходы

| Величина | Единица | Примечание |
|---|---|---|
| Вес | кг | Суммарный вес стержня |
| Площадь | м² | Условная — у источника показывает 0 м², видимо не реализовано |
| Средняя цена × масса | руб. | Опциональный маркетинговый блок |

#### Формула

Арматура — не простой цилиндр. Вес берётся из таблицы **ГОСТ 5781-82**, где для каждого номинального диаметра задан теоретический вес единицы длины m₁ в кг/м:

```
m = m₁ × L
```

Значения m₁ по ГОСТ 5781-82:

| d, мм | m₁, кг/м |
|---|---|
| 6 | 0.222 |
| 8 | 0.395 |
| 10 | 0.617 |
| 12 | 0.888 |
| 14 | 1.208 |
| 16 | 1.578 |
| 18 | 1.998 |
| 20 | 2.466 |
| 22 | 2.984 |
| 25 | 3.853 |
| 28 | 4.834 |
| 32 | 6.313 |
| 36 | 7.990 |

Значения учитывают поперечные рёбра (профиль арматуры классов А400 / А500С). Плотность стали 7 850 кг/м³ принята в расчёте ГОСТ, пользователь её не задаёт.

#### Численный пример

Входы: d = 10 мм, L = 1 м → **m = 0.617 кг** (источник: 0.616 кг).
Практика: 10 прутков d=12, L=6 м → m = 0.888 × 6 × 10 = **53.3 кг**.

#### Связь с нашим каталогом

Арматура у нас не продаётся (нержавеющая арматура — крайне узкая ниша). Рекомендуется **отдельная посадочная** `/kalkulyator-armatury/` для SEO-трафика с примечанием, что мы работаем с нержавеющим прокатом, и призывом к переходу в каталог.

#### Инфографика

**Тип:** ортогональная проекция, вид на торец — 2D схема сечения.

**Композиция:** квадратный кадр. В центре — круглое сечение арматурного стержня диаметром ~70% высоты холста. Осевые пунктирные линии крест-накрест делят круг на 4 квадранта. По бокам круга (на 3 и 9 часах) — два малых выступа (схематичные поперечные рёбра, D-образные «ушки» шириной ~3–4% диаметра).

**Размеры:** D — наружный диаметр: двусторонняя горизонтальная стрелка под кругом от края до края, подпись «D» в центре под стрелкой.

**Стиль линий:** контур круга — толстая линия (1.5–2 px). Рёбра — тонкий контур. Внутри сечения — диагональная штриховка 45° (левый наклон) с равным шагом. Осевые линии — тонкие пунктирные. Без 3D и градиентов.

**Цвета:** чёрно-белое. Контур чёрный, заливка — штриховка, фон белый/светло-серый.

**Подписи:** только латинская «D», шрифт sans-serif.

**Что менять при переносе:** контур `var(--color-primary)` (синий), стрелки `var(--color-accent)` (оранжевый), шрифт Inter. Добавить подпись «Арматура А500С / ГОСТ 5781-82» мелким текстом.

### 2. Калькулятор веса балки двутавровой

**Источник:** `/kalkulyator-vesa-metalloprokata/kalkulyator-vesa-balki-dvutavrovoy-dvutavra`
**Что считает:** масса двутавровой балки заданного типа и длины.
**Применение:** проектировщики металлоконструкций подбирают двутавр под нагрузку и считают вес металла для сметы.

#### Входы

| Поле | Единица | Тип | Дефолт | Варианты |
|---|---|---|---|---|
| Тип балки | — | dropdown | Нормальный двутавр (Б) | ГОСТ 8239-89; Б; Ш (широкополочный); К (колонный); Д (дополнительной серии); С (сварной) |
| Номер балки | — | dropdown | 10Б1 | Зависит от типа: для ГОСТ 8239-89 — 10, 12, 14…60; для Б — 10Б1…100Б4 (37 позиций) |
| Длина L | м | text input | 0 | > 0 |

Кнопки режима: **Расчёт веса** / **Расчёт длины**.

#### Выходы

| Величина | Единица |
|---|---|
| Вес | кг (= m₁ × L) |

#### Формула

```
m = m₁ × L
```

m₁ — линейный вес из ГОСТ 8239-89 (обычный двутавр) или ГОСТ 26020-83 (Б, Ш, К-серии).

Пример значений m₁ по ГОСТ 8239-89:

| 12 | 11.50 |
| 14 | 13.70 |
| 16 | 15.90 |
| 18 | 18.40 |
| 20 | 21.00 |
| 27 | 31.50 |
| 30 | 36.50 |
| 40 | 57.00 |

Пример значений Б-серии (ГОСТ 26020-83):

| Профиль | m₁, кг/м |
|---|---|
| 10Б1 | 8.10 |
| 20Б1 | 17.90 |
| 30Б1 | 28.00 |
| 40Б1 | 39.80 |

#### Численный пример

ГОСТ 8239-89, Номер 20, L = 1 м → **21.000 кг** (проверено).
Б-серия, 10Б1, L = 1 м → **8.100 кг** (проверено).

#### Связь с каталогом

Двутавр у нас не продаётся. Та же модель, что и арматура: SEO-лендинг `/kalkulyator-balki/` с переходом к нашим трубам/уголкам как альтернативным несущим профилям.

#### Инфографика

**Тип:** 2D ортогональная проекция, разрез торца — схема поперечного сечения двутавра.

**Композиция:** горизонтальный кадр 4:3 или 3:2. В центре — I-образное сечение. Высота балки ~2/3 высоты рисунка. Стандартная ориентация: полки горизонтальны, стенка вертикально.

**Размеры (для 10Б1):**
- h = 100 мм (высота): вертикальная двусторонняя стрелка слева, подпись «100»
- b = 55 мм (ширина полки): горизонтальная стрелка под нижней полкой, подпись «55»
- tw = 4.1 мм (толщина стенки): горизонтальная стрелка по середине стенки, подпись «4.1»
- tf = 5.7 мм (толщина полки): вертикальная стрелка у правого края нижней полки, подпись «5.7»

**Стиль:** контур — толстая чёрная линия. Внутри — диагональная штриховка 45°. Переходы стенка-полка скруглены.

**Цвета:** чёрно-белое.

**Подписи:** только числа (100, 4.1, 5.7, 55), без буквенных обозначений.

**Что менять:** добавить обозначения h, b, t_w, t_f. Стрелки оранжевые, контур синий, шрифт Inter.

### 3. Калькулятор веса швеллера

**Что считает:** масса стального швеллера по номеру профиля и длине.
**Применение:** строительные и промышленные конструкции — перемычки, каркасы, опорные элементы. Нержавеющий швеллер используется в пищевой промышленности, судостроении.

| 24П | 24.00 |

#### Численный пример

#### Связь с каталогом

Нержавеющий швеллер — раздел `/ugolok-shveller/`. Создать `/kalkulyator-shvellera/` с двумя режимами: «по ГОСТ (выбор номера)» и «по размерам (h, b, t)» — второй даёт гибкость для нестандарта.

#### Инфографика

**Тип:** 2D ортогональная проекция, вид на торец П-образного профиля.

**Композиция:** вертикальный или квадратный кадр. В нижней трети — горизонтальная нижняя полка (со штриховкой). От левого края полки вертикально вверх — стенка. От верха стенки горизонтально вправо — верхняя полка. Получается русская буква «П» открытой стороной вправо.

**Размеры (для 5П):**
- h = 50 мм: вертикальная стрелка левее стенки, подпись «50»

- tw = 4.4 мм: стрелка внутрь стенки, подпись «4.4»

**Стиль:** контур толстый, штриховка 45°, углы переходов прямые или слабо скруглённые.

**Цвета:** чёрно-белое.

**Подписи:** числа без буквенных обозначений.

**Что менять:** добавить h, b, t_w. Наша палитра.

| Ширина полки a | мм | text input | 0 | Горизонтальная полка |
| Высота полки b | мм | text input | 0 | Вертикальная полка, может = a |
| Толщина t | мм | text input | 0 | Одинакова для обеих полок |
| Длина L | м | text input | 0 | > 0 |

Кнопки режима: **Расчёт веса** / **Расчёт длины**.

#### Формула

```
m = (a + b − t) × t × L × ρ / 1 000 000
```

При SI: a, b, t в мм; L в м; ρ в кг/м³; результат m в кг.

Расшифровка: (a + b − t) — суммарная длина средней линии сечения без двойного счёта угла; t — толщина полки; L — длина; ρ — плотность (7 850 для Ст3, 7 900 для аустенитной нержавейки, 7 700 для ферритной).

> Формула без учёта скруглений в углах. Для ГОСТ-значений применяются справочные таблицы с учётом наружных и внутренних галтелей.

#### Численный пример

Нержавейка 12Х18Н10Т (ρ = 7 900), a = 50, b = 32, t = 4, L = 1 м:
m = (50 + 32 − 4) × 4 × 1 × 7900 / 1 000 000 = 78 × 4 × 7900 / 1 000 000 = **2.465 кг/м** ✓ (проверено).

Ст3 (ρ = 7 850), те же размеры: 78 × 4 × 7850 / 1 000 000 = **2.450 кг/м** (источник: 2.434 — разница из-за галтелей).

#### Связь с каталогом

Добавить **режим «неравнополочный»** в существующий калькулятор уголка в `/kalkulyator-vesa/`: при a = b получается равнополочный, при a ≠ b — неравнополочный. Один калькулятор с двумя полями a и b вместо одного «полка».

#### Инфографика

**Тип:** 2D проекция сечения, вид на торец L-образного профиля.

**Композиция:** квадратный или слегка вертикальный кадр. Г-образная (зеркальная Г) фигура: вертикальная полка b слева, горизонтальная a внизу, угол в левом нижнем углу. Обе полки заштрихованы. Открытая сторона уголка — вправо и вверх.

**Размеры:**
- a — горизонтальная стрелка под нижней полкой, подпись «a»
- b — вертикальная стрелка левее вертикальной полки, подпись «b»
- t — стрелка поперёк стенки, подпись «t» справа

**Стиль:** контур толстый, штриховка 45°, без скруглений.

**Цвета:** чёрно-белое.

**Что менять:** показать наглядно a ≠ b разными цветами стрелок или подписью «неравнополочный». Наша палитра.

### 5. Калькулятор веса отвода (крутоизогнутого)

**Источники:**
- Чёрный: `/kalkulyator-vesa-metalloprokata/kalkulyator-vesa-stalnogo-otvoda`
- Нержавейка: `/kalkulyator-vesa-nerzhaveyuschego-metalloprokata/kalkulyator-vesa-nerzhaveyuschego-otvoda`

**Что считает:** масса одного (или N штук) крутоизогнутого отвода трубопровода по ГОСТ 17375-2001.
**Применение:** монтажники трубопроводов рассчитывают вес деталей для транспортировки, такелажа и сметы. Нержавеющие отводы — наша профильная позиция (есть в `/detali-truboprovoda/`).

#### Входы

| Поле | Единица | Тип | Дефолт | Варианты |
|---|---|---|---|---|
| Исполнение | — | dropdown | Исп. 2 | Исп. 1 (R = 1.5 D); Исп. 2 (R = 1.0 D); по ГОСТ 17375-2001 |
| Угол отвода α | ° | dropdown | 90 | 45, 60, 90, 180 |
| Размер DN × t | мм | dropdown | 32×2 | 32×2 … 630×12 (100+ позиций) |
| Материал / марка | — | dropdown | Ст20 / 12Х18Н10Т | По стандарту |
| Количество | шт. | text input | 1 | целое ≥ 1 |

#### Выходы

| Величина | Единица | Примечание |
|---|---|---|
| Вес 1 шт. | кг | По геометрии или ГОСТ-таблице |
| Общий вес | кг | вес 1 × количество |
| Объём металла | см³ | опционально |

#### Формула

Геометрически отвод — сегмент тора. Площадь кольцевого сечения трубы × длина дуги осевой линии × плотность:

```
m = π · (D − t) · t · (π · R · α / 180°) · ρ / 10⁹
```

где:
- D — наружный диаметр трубы (мм)
- t — толщина стенки (мм)
- R — радиус оси отвода (мм): для Исп. 1 R = 1.5 D, для Исп. 2 R = 1.0 D
- α — угол отвода в градусах
- ρ — плотность металла (кг/м³): 7 850 углеродистая сталь; 7 900 аустенитная нержавейка (304/316L/321); 7 700 ферритная (430)
- делитель 10⁹ переводит мм³·кг/м³ в кг

Практика источника, как для арматуры и балки, — табличные значения из приложений к ГОСТ 17375-2001 (учитывают допуски и реальную геометрию торцов). Геометрическая формула расходится с табличной на 1–3 %.

#### Численный пример

DN 100, t = 4 мм, Исп. 2 (R = 100 мм), α = 90°, нержавейка 12Х18Н10Т:
- кольцевая площадь = π × (100 − 4) × 4 = 1 206 мм²
- длина дуги оси = π × 100 × 90 / 180 = 157 мм
- объём = 1 206 × 157 = 189 525 мм³
- m = 189 525 × 7 900 / 10⁹ = **1.50 кг** (табличное по ГОСТ ~1.52 кг)

DN 32, t = 3 мм, Исп. 2 (R = 32 мм), α = 90°, Ст20:
- m = π × 29 × 3 × π × 32 × 90/180 × 7 850 / 10⁹ ≈ **0.108 кг** (табличное ~0.11 кг)

#### Связь с каталогом

`/detali-truboprovoda/` — отводы уже в каталоге. Создать `/kalkulyator-otvoda/` с предвыбором нержавейки и кросс-линком на раздел.

#### Инфографика

**Тип:** 2D вид сбоку — четверть кольца (срез тора по плоскости симметрии) + врезка с кольцевым сечением трубы.

**Композиция:** квадратный кадр. По центру — изогнутая под 90° труба, нарисованная двумя концентрическими дугами (наружная и внутренняя стенка). Один конец направлен горизонтально вправо, второй — вертикально вверх. Из центра кривизны (нижний-левый угол кадра) — пунктирный луч к оси трубы, обозначающий радиус R. На каждом конце трубы — короткая прямая «фаска» торца со штриховкой 45°, чтобы показать рассечение.

**Размеры:**
- D — наружный диаметр: на правом (горизонтальном) торце вертикальная двусторонняя стрелка от верхней до нижней образующей, подпись «D» справа от стрелки
- t — толщина стенки: маленькая стрелка через кольцо стенки на правом торце, подпись «t» крупнее, с выноской
- R — радиус оси отвода: пунктирная линия от центра кривизны до оси, подпись «R» вдоль линии, маленький значок центра в начале (крестик)
- α = 90° — дуга-индикатор угла в центре кривизны, подпись «90°»

**Стиль линий:** контуры — толстая основная линия. Штриховка торцов 45°. Оси и радиусные линии — штрих-пунктир. Стрелки тонкие, с открытыми наконечниками.

**Цвета (наша палитра):** контур `var(--color-primary)` (синий), штриховка и стрелки `var(--color-accent)` (оранжевый), подписи — тёмно-серые. Фон белый.

**Подписи:** «D», «t», «R», «90°» — шрифт Inter, мелкий. Внизу кадра — мелкая сноска «ГОСТ 17375-2001».

### 6. Калькулятор веса фланца плоского приварного

**Источники:**
- Чёрный: `/kalkulyator-vesa-metalloprokata/kalkulyator-vesa-stalnogo-flantsa`
- Нержавейка: `/kalkulyator-vesa-nerzhaveyuschego-metalloprokata/kalkulyator-vesa-nerzhaveyuschego-flantsa`

**Что считает:** масса плоского приварного фланца по ГОСТ 33259-2015 (актуальный) или ГОСТ 12820-80 (старый, ещё в обороте).
**Применение:** разъёмные соединения трубопроводов и арматуры. Нержавеющие фланцы — в нашем каталоге `/detali-truboprovoda/`.

#### Входы

| Поле | Единица | Тип | Дефолт | Варианты | Примечание |
|---|---|---|---|---|---|
| Стандарт | — | dropdown | ГОСТ 33259-2015 | ГОСТ 33259-2015; ГОСТ 12820-80; ГОСТ 12821-80 (приварной встык) | |
| Тип (по 33259) | — | dropdown | Тип 01 | 01, 02, 03, 04, 05, 11 | 01 — плоский приварной, самый ходовой |
| DN (условный проход) | мм | dropdown | 50 | 10, 15, 20, 25, 32, 40, 50, 65, 80, 100, 125, 150, 200, 250, 300, 350, 400, 500, 600, 800, 1000 | |
| PN (давление) | МПа | dropdown | 1.0 | 0.6, 1.0, 1.6, 2.5, 4.0, 6.3, 10, 16, 25 | Определяет габариты |
| Материал / марка | — | dropdown | Ст20 / 12Х18Н10Т | По стандарту | |
| Количество | шт. | text input | 1 | целое ≥ 1 | |

#### Выходы

| Величина | Единица |
|---|---|
| Вес 1 шт. | кг |
| Общий вес | кг |

#### Формула

Геометрия плоского диска с центральным проёмом за вычетом n болтовых отверстий:

```
m = [ (π/4) · (D² − d²) − n · (π/4) · d_б² ] · H · ρ / 10⁹
```

где:
- D — наружный диаметр фланца (мм)
- d — внутренний диаметр (под трубу) (мм)
- D_б — диаметр болтовой окружности (мм) (не входит в формулу массы, но нужен для чертежа)
- d_б — диаметр болтового отверстия (мм)
- n — количество болтовых отверстий
- H — толщина диска (мм)
- ρ — плотность (кг/м³)

На практике источник, как и для арматуры/балки/отводов, **берёт готовые табличные значения** из приложений к ГОСТ 33259-2015 (раньше — таблицы ГОСТ 12820-80). Геометрическая формула расходится с табличной на 3–5 % из-за фасок, скруглений кромки, исполнения уплотнительной поверхности (B, C, D — выступ-впадина, шип-паз).

#### Численный пример

DN 100, PN 10, ГОСТ 33259-2015, тип 01, нержавейка 12Х18Н10Т:
- D = 220 мм
- d = 112 мм (под трубу Ø108)
- D_б = 180 мм
- d_б = 18 мм
- n = 8
- H = 18 мм
- площадь диска: π/4 × (220² − 112²) = 0.7854 × 35 856 = 28 158 мм²
- площадь отверстий: 8 × π/4 × 18² = 2 036 мм²
- объём: (28 158 − 2 036) × 18 = 470 196 мм³
- m = 470 196 × 7 900 / 10⁹ = **3.71 кг** (табличное по ГОСТ ~3.66 кг)

DN 50, PN 16, ГОСТ 12820-80, Ст20:
- D = 160, d = 61, d_б = 18, n = 4, H = 16, ρ = 7 850
- m ≈ **2.05 кг** (табличное ~2.0 кг)

#### Связь с каталогом

`/detali-truboprovoda/` — фланцы там есть. Создать `/kalkulyator-flantsa/`:
- основной режим — **табличный по ГОСТ** (выбор DN + PN → готовые массы);
- альтернативный — **формульный** для нестандартных размеров.

#### Инфографика

**Тип:** комбинированная — вид сверху на круг + вертикальный разрез сбоку.

**Композиция:** горизонтальный кадр 4:3. Левая половина — вид сверху на фланец: большой внешний круг диаметром D, концентрический внутренний круг диаметром d, между ними равномерно по окружности радиуса D_б/2 — n маленьких кружков диаметром d_б (для DN 100 — 8 штук под 45°). Правая половина — вертикальный разрез: тонкий прямоугольник высотой H с центральным проёмом диаметром d, со штриховкой 45°; справа от прямоугольника показано одно болтовое отверстие сквозь толщину штрихом.

**Размеры:**
- D — наружный диаметр: на виде сверху двусторонняя горизонтальная стрелка через центр, подпись «D» сверху
- d — внутренний диаметр: внутренняя стрелка короче, подпись «d»
- D_б — диаметр болтовой окружности: пунктирная окружность через центры болтовых отверстий, подпись «Dб» с выноской на саму окружность
- d_б — диаметр болтового отверстия: маленькая стрелка через одно отверстие в правом верхнем углу окружности, подпись «dб»
- H — толщина: на разрезе вертикальная стрелка справа, подпись «H»
- n × d_б = 8 × Ø 18 — текстовая подпись внизу под видом сверху

**Стиль линий:** наружный контур — толстый, болтовая окружность — пунктир, осевые — штрих-пунктир крестом, штриховка разреза 45°. Стрелки тонкие с открытыми наконечниками.

**Цвета (наша палитра):** контур `var(--color-primary)`, стрелки и оси `var(--color-accent)`, штриховка светло-серая. Фон белый.

**Подписи:** «D», «d», «Dб», «dб», «H», «n=8» — шрифт Inter, мелкий. Внизу — мелкая сноска «ГОСТ 33259-2015 / тип 01».
