# ИТЗ для Claude-агента в Chrome: исследование metal-calculator.ru

> Документ — постановка задачи для Claude-агента, который работает в браузере Chrome.
> Цель — собрать полный набор формул, входов/выходов и описаний картинок, чтобы у нас на сайте появились **недостающие** калькуляторы металлопроката с собственной векторной инфографикой.

---

## 0. Контекст проекта

- Сайт: `gkmetallinvest.vercel.app` (прод-копия `gkmetallinvest.ru` пока на Tilda).
- Тематика: нержавеющий металлопрокат (лист, рулон, труба круглая и профильная, круг, квадрат, шестигранник, полоса, проволока, уголок, швеллер, детали трубопровода).
- Стек: Astro 6, статика, без бэкенда. Калькулятор должен работать на чистом TS/JS на клиенте.
- Существующая страница калькулятора: `/kalkulyator-vesa/`.

---

## 1. Что у нас уже реализовано (НЕ исследовать и НЕ предлагать заново)

Универсальный «Калькулятор веса» на 9 видов проката. Все они уже умеют: ввод размеров в мм → вычисление массы единицы (кг/м, кг/м², кг/лист), общей массы для N единиц, объёма, обратный пересчёт «нужно X тонн → сколько штук», копирование результата, передача параметров в форму запроса КП.

Реализованные виды и поля ввода:

| Вид | Поля ввода | Единица результата |
|---|---|---|
| Лист | толщина, ширина, длина | кг/лист |
| Полоса | толщина, ширина, длина | кг/шт |
| Круг | диаметр, длина | кг/м |
| Квадрат (пруток) | сторона, длина | кг/м |
| Шестигранник | размер «под ключ» (через грани), длина | кг/м |
| Труба круглая | наружный диаметр, стенка, длина | кг/м |
| Труба профильная (прямоугольная/квадратная) | сторона A, сторона B, стенка, длина | кг/м |
| Проволока | диаметр, длина | кг/м |
| Уголок (равнополочный) | полка, толщина, длина | кг/м |

Группы плотности (выбираются кнопкой, ρ подставляется автоматически):
- Аустенитные (304, 316L, 321, 12Х18Н10Т, 201) — 7,9 г/см³
- Ферритные (430, 410S, 439) — 7,7 г/см³
- Мартенситные (420, 440, 20Х13) — 7,7 г/см³
- Дуплекс / двухфазные — 7,8 г/см³
- «Другая» — пользователь вводит ρ вручную

**Что считается покрытым и в новой версии НЕ нужно:**
- Любые «вес листа / трубы / круга / квадрата / шестигранника / уголка равнополочного / проволоки / профильной трубы прямоугольной».
- Конвертация «масса ↔ штуки/метры» для тех же 9 видов.
- Универсальный выбор группы марок по плотности.

## 2. Цель исследования

Пройти `https://metal-calculator.ru/` и собрать:

1. **Полный список калькуляторов**, которые у них есть, с указанием URL каждого.
2. По каждому калькулятору — **отметить «есть у нас / нет у нас»**, опираясь на таблицу из раздела 1.
3. Для всех «нет у нас»:
   - Входные параметры (с единицами измерения и допустимыми диапазонами, если видны).
   - Что считает (масса, площадь, объём, расход, длина и т. д.).
   - Формула (записать символьно, например `m = π · (D − s) · s · L · ρ`).
   - Численный пример: для типичных входов привести результат — нужно для проверки.
   - Какая марка/материал по умолчанию (нержавейка, сталь общего назначения, алюминий, цветмет — указать).
4. Для каждого калькулятора (включая «есть у нас» — там тоже нужно) — **подробное описание картинки/инфографики**, по которому художник может с нуля нарисовать векторную схему (см. формат в разделе 5).
5. Список калькуляторов, которые **расширяют** уже существующие (например, у нас уголок только равнополочный — у них может быть неравнополочный; у нас трубы простые — у них могут быть овальные, плоскоовальные).

## 3. Сценарий обхода сайта

Идти методически, не перескакивая:

1. Открыть главную `https://metal-calculator.ru/?ref=xranks`. Снять список всех разделов меню — каталога калькуляторов.
2. По каждому пункту меню/каталога:
   - Открыть страницу калькулятора.
   - Сделать **скриншот общего вида** (для отчёта) + отдельно **скриншот картинки/схемы проката** — она нужна для описания инфографики.
   - Записать URL, заголовок, поля ввода (label, единицы, дефолтные значения, шаг).
   - Записать выводимые величины (что показывается после расчёта).
   - Из текста страницы или из подсказок выудить формулу. Если формула не написана явно — восстановить по виду проката (стандартная геометрия + плотность).
3. Дойти до карты сайта/футера, проверить что ничего не пропущено.
4. Отдельно собрать список **сопутствующих инструментов**, не относящихся к расчёту веса:
   - Калькуляторы количества (сколько листов на крышу/фасад, сколько арматуры на куб бетона и т. п.).
   - Калькуляторы стоимости (если есть привязка к цене).
   - Калькуляторы прочности/прогиба/момента сопротивления, если они там есть.
   - Конвертеры (масса ↔ длина ↔ количество).
   - Справочные таблицы (ГОСТы, сортаменты).

**Важные ограничения агента:**
- Файлы (PDF, XLS, изображения) **не качать** — у агента в браузере нет такой возможности. Если попался PDF/XLS — открыть его в браузере и описать содержимое словами или вернуть прямую ссылку.
- Поиск чего-либо вне сайта вести через **Яндекс или Google**, не через Pinterest.

Один Markdown-документ со следующими разделами:

|---|---|---|---|---|---|

Приоритет ставит сам агент по эвристике:

- 4 — расширение уже существующего (например, неравнополочный уголок, овальная труба).
- 3 — узкие специальные расчёты (количество кирпича, бетон, кровля) — могут быть полезны для трафика, но не профильны.
- 2 — нишевые/редкие.
- 1 — конвертеры и калькуляторы, дублирующие то, что у нас уже есть.

## 5. Формат описания инфографики (это ключевая часть)

Для каждой картинки/схемы проката на сайте источника **описать словами так подробно, чтобы дизайнер мог из текста воссоздать векторную схему без обращения к исходнику**. Никаких файлов скачивать не нужно — нужен текст.

Шаблон описания одной картинки:

```
### Инфографика: <название проката>

**Тип изображения**: 3D-изометрия / ортогональная проекция (вид сбоку + торец) / схематичный 2D.

**Композиция кадра**:
- Что в центре (например: отрезок трубы длиной ~3 диаметра, повернут на ~30° к зрителю).
- Где торец (слева/справа), как он показан (отдельным кружком с выноской, или прямо на самом изделии).
- Соотношение сторон рисунка (квадрат / горизонтальный 4:3 / вертикальный).

**Какие размеры подписаны и как**:
- D — наружный диаметр: стрелка-двусторонняя горизонтально через торец, подпись «D» сверху от стрелки.
- s — толщина стенки: стрелка от внутренней стенки к наружной, подпись «s» сбоку, мелким курсивом.
- L — длина: стрелка вдоль оси трубы внизу, подпись «L» по центру.
(перечислить ВСЕ обозначения, какие реально присутствуют)

**Стиль линий**:
- Тип контура (тонкий, толстый, со штриховкой; цвет, если есть).
- Заштрихованы ли срезы (штриховка под 45°? сетка?).
- Используются ли пунктиры для скрытых линий (внутренний диаметр трубы и т. д.).

**Цвета и заливки**:
- Какие цвета у самой детали (металлик / серый / без заливки только контур).
- Цвета подписей и стрелок.
- Есть ли фон (нет / светло-серый / градиент).

**Подписи и шрифт**:
- Какие подписи есть (D, s, L; «наружный диаметр»; и т. д.).
- Кириллица / латиница / смешано.

**Дополнительные элементы**:
- Стрелка-указатель «направление длины», система координат, мелкие иконки, логотип источника (его НЕ переносим).

**Что нужно изменить при переносе к нам**:
- Логотип / водяные знаки источника — не использовать.
- Цвета привести к нашей палитре (синий `var(--color-primary)` + оранжевый акцент `var(--color-accent)`).
- Подписи — на русском, шрифт Inter, как на остальном сайте.
```

> **ВАЖНО про copyright:** мы не копируем дизайн и не «слегка переделываем» чужие SVG. Из описания мы воссоздаём свою векторную схему с нуля — другие пропорции, наша палитра, наш шрифт. Формулы геометрии — общеинженерные, прав на них нет. Тексты на наших страницах пишем сами, не репостим у источника.

## 6. Что отдельно поискать (особый интерес)

Это вещи, которых у нас почти наверняка нет, и они дают большой SEO-поток. Если найдутся у источника или поблизости — расписать максимально подробно.

1. **Расчёт веса арматуры** (рифлёной A500C/A400) — диаметр, длина, в т ч пачкой.
2. **Расчёт веса балки двутавровой** (Б, Ш, К — Б1…Б40, ГОСТ 26020-83).
3. **Расчёт веса швеллера** (П- и У-образного, ГОСТ 8240-97) — у нас уголок есть, швеллера полноценно нет.
4. **Расчёт веса уголка неравнополочного** (полки A и B + толщина t).
5. **Расчёт веса рифлёного листа** (ромб, чечевица) — поверхностная плотность отличается от гладкого листа.
6. **Расчёт веса просечно-вытяжного листа (ПВЛ)**.
7. **Расчёт веса труб овальных и плоскоовальных** (для перильных систем — ходовой сортамент в нержавейке).
8. **Расчёт веса проволочной/сварной сетки** (ячейка × проволока × габарит карты).
9. **Расчёт массы рулона нержавейки** по наружному и внутреннему диаметру рулона + ширина ленты + толщина (через площадь спирали).
10. **Стоимость единицы по цене за тонну** (вход: масса в кг + цена ₽/т → выход: цена позиции).
