# Чек-лист по 152-ФЗ для ООО «МЕТАЛЛИНВЕСТ»

**Документ для клиента.** Разделение обязанностей по обработке персональных данных между разработчиком сайта и оператором ПДн (вашей компанией).

Дата: 2026-06-15

---

## Кто за что отвечает по закону

По Федеральному закону № 152-ФЗ «О персональных данных» оператором персональных данных является **тот, кто определяет цели и средства обработки ПДн** — то есть **ваша компания**, потому что:

- именно вы получаете заявки клиентов и работаете с ними;
- именно ваш менеджер звонит клиенту и записывает разговор в UIS Comagic;
- именно ваш amoCRM хранит карточки клиентов;
- именно ваш бизнес заключает договоры поставки.

**Разработчик сайта** (исполнитель) к обработке ПДн юридического отношения не имеет — мы только строим инструмент (сайт), через который форма попадает в ваш amoCRM. Все обязанности по 152-ФЗ лежат на операторе.

### Аналогия

Это как с офисом: подрядчик строит здание и сдаёт его арендатору. Дальше за пожарную безопасность, СЭС, ОТ и охрану отвечает арендатор, а не строитель.

## Что нужно сделать клиенту — подробно

### 1. Уведомление в Роскомнадзор

**Что это.** Один раз заявить в РКН, что ООО «МЕТАЛЛИНВЕСТ» обрабатывает ПДн посетителей сайта и клиентов. Попадаете в публичный реестр операторов.

**Как.**
1. Сначала проверьте, нет ли вас уже в реестре: https://pd.rkn.gov.ru/operators-registry/operators-list/ — поиск по ИНН **5262332690**.
2. Если нет — подайте через сайт РКН: https://pd.rkn.gov.ru/operators-registry/notification/form/
3. Удобнее через Госуслуги: https://www.gosuslugi.ru/600373/1/form
4. Подписывается ЭП руководителя (Галанов А. О.) или КЭП юрлица.
5. Рассматривают 30 дней, после чего вы в реестре.

**Что писать в форме.** Все нужные сведения уже зафиксированы в Политике конфиденциальности (`/politika-konfidencialnosti/` на сайте). В частности:

| Поле формы РКН | Значение |
|---|---|
| Наименование оператора | ООО «МЕТАЛЛИНВЕСТ» |
| ИНН / ОГРН / КПП | 5262332690 / 1165262052889 / 526001001 |
| Юридический адрес | 603006, Нижний Новгород, ул. Варварская, 32, П5, оф. 417 |
| Цели обработки ПДн | См. п. 4 Политики (заявки с сайта, договоры поставки, бух. учёт, информирование, маркетинг по согласию) |
| Категории ПДн | ФИО, телефон, e-mail, реквизиты ЮЛ, IP, cookie, аудиозаписи звонков |
| Категории субъектов | Посетители сайта, клиенты-физлица и представители юрлиц, контрагенты |
| Перечень действий | Сбор, запись, систематизация, хранение, уточнение, использование, передача, удаление |
| Способы обработки | Автоматизированная (формы сайта, amoCRM, бух. ПО) и неавтоматизированная (бумажные договоры) |
| Меры защиты | Назначен ответственный, HTTPS, разграничение доступа в amoCRM, СНГ с сотрудниками |
| Дата начала обработки | Дата запуска сайта / регистрации юрлица |
| Трансграничная передача | Не осуществляется |
| Сведения о локализации БД | На территории РФ (серверы amoCRM, UIS Comagic, Яндекс.Метрики, хостинг — в РФ) |

**Штраф за неподачу:** 100–300 тыс. ₽ для юрлица (ч. 10 ст. 13.11 КоАП).

### 2. Приказ о назначении ответственного за обработку ПДн

**Что это.** Внутренний приказ за подписью директора, что в ООО «МЕТАЛЛИНВЕСТ» назначен ответственный за организацию обработки ПДн (ст. 22.1 ФЗ-152).

**Кто ответственный.** Обычно сам директор (Галанов А. О.) либо другой сотрудник, имеющий доступ к amoCRM и принимающий заявки.

**Шаблон приказа** — могу выслать отдельно по запросу (.docx, одна страница).

**Где хранится:** в папке кадровых документов компании. При проверке РКН — первое, что просят показать.

---

### 3. Договоры поручения с сервисами обработки ПДн

**Что это.** По ч. 3 ст. 6 ФЗ-152 — если вы передаёте чужие ПДн стороннему сервису, должен быть документ, где сервис обязуется их защищать.

**Хорошая новость.** У вас уже есть такие договоры — это **публичные оферты сервисов, которые вы приняли при регистрации**. Нужно только сохранить их PDF-копии в папку «Документы по ПДн»:

| Сервис | Где найти DPA |
|---|---|
| amoCRM | https://www.amocrm.ru/legal/dpa |
| UIS Comagic | В личном кабинете: «Документы» → «Соглашение об обработке персональных данных» |
| Яндекс.Метрика | https://yandex.ru/legal/metrica_termsofuse/ + https://yandex.ru/legal/confidential/ |
| Хостинг (Vercel / TimeWeb / Selectel) | В личном кабинете провайдера, раздел документов |

**Отдельно подписывать ничего не нужно** — при регистрации в каждом из сервисов вы уже акцептовали оферту.

---

### 4. Учёт согласий клиентов

**Что это.** Журнал, кто и когда дал согласие на обработку ПДн.

**Как реализовать у вас.** Поскольку все заявки идут в amoCRM, журнал = сама CRM. Добавьте в карточку сделки **два кастомных поля**:

- `Согласие на обработку ПДн (152-ФЗ)` — галочка, заполняется автоматически при поступлении заявки с сайта (форма сайта отправляет `consent_pd=on`).
- `Согласие на маркетинговые рассылки (38-ФЗ)` — галочка, заполняется только если клиент отметил опциональный чек-бокс на сайте (`consent_marketing=yes`).

Это сделает интегратор amoCRM при настройке вебхука от сайта. Если интеграции пока нет — нужно поручить тому, кто будет настраивать передачу заявок с формы в amoCRM.

---

### 5. Локальные акты компании (вторая очередь)

Желательны, требуются при серьёзной проверке РКН:

- **Положение об обработке и защите ПДн** — внутренний документ на 5–10 страниц, описывает порядок работы с ПДн в компании.
- **Перечень ПДн и мест хранения** — какие данные где лежат (amoCRM, бух. ПО, бумажные договоры).
- **Модель угроз безопасности ПДн** — типовая, по методике ФСТЭК.
- **Соглашения о неразглашении** с сотрудниками, имеющими доступ к amoCRM (менеджеры, бухгалтер).

Это шаблонные документы, любой юрист по ПДн оформит за день. Стоимость пакета у профильного консультанта — около 15–40 тыс. ₽.
