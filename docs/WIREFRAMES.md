# Wireframes (описание макетов)

Формат: блоковая схема для desktop; мобильные отличия указаны отдельно.

## 1. Главная

```
┌─────────────────────────────────────────────────────────────┐
│ HEADER: логотип | Каталог ▼ | Лист … Услуги | тел | Заявка  │
├─────────────────────────────────────────────────────────────┤
│ HERO: H1 + УТП + [Запросить цену] [Каталог] [Заявка]        │
├─────────────────────────────────────────────────────────────┤
│ СЕТКА 2×3: карточки Лист | Труба | Круг | Лента | Рулон | Декор│
├─────────────────────────────────────────────────────────────┤
│ Популярные направления (чипы/ссылки на марки и хабы)         │
├─────────────────────────────────────────────────────────────┤
│ Услуги: 3–6 карточек (резка, перфорация, шлифование…)        │
├─────────────────────────────────────────────────────────────┤
│ География: «По всей РФ» + список городов (сетка)            │
├─────────────────────────────────────────────────────────────┤
│ Преимущества (иконки + короткий текст)                       │
├─────────────────────────────────────────────────────────────┤
│ Марки AISI (ряд кнопок/карточек)                             │
├─────────────────────────────────────────────────────────────┤
│ Форма заявки (имя, телефон, email, комментарий)              │
├─────────────────────────────────────────────────────────────┤
│ FAQ (аккордеон)                                              │
├─────────────────────────────────────────────────────────────┤
│ FOOTER: меню, реквизиты, контакты                            │
└─────────────────────────────────────────────────────────────┘
```

**Mobile:** hero → сетка категорий 1 колонка; липкая панель внизу: [Позвонить] [Заявка].

## 2. Хаб каталога (например «Лист»)

```
Хлебные крошки
H1 + лид
Поднавигация: подкатегории / марки / поверхности (табы или сетка ссылок)
[Фильтр] — свёрнут превью; кнопка «Все фильтры»
Блок параметров (таблица или карточки строк)
Услуги (перекрёстные ссылки)
Преимущества + CTA
FAQ
Блок «Доставка по РФ»
```

**Mobile:** фильтр в bottom sheet; таблица → горизонтальный скролл или карточки.

## 3. Страница услуги (например «Резка рулонов»)

```
Хлебные крошки
H1 под задачу («Продольная и поперечная резка рулонов»)
Кратко: что делаем, для каких материалов
Оборудование / точность / толщины
Связанные товары: карточки → /rulon/, /lenta/
CTA + форма
```

## 4. Липкий mobile CTA

```
┌──────────────────────────┐
│                          │
│      (контент страницы)   │
│                          │
├──────────────────────────┤
│ [ 📞 Звонок ] [ Заявка ] │  ← height ~56px, safe-area inset
└──────────────────────────┘
```

Кнопка «Заявка» скроллит к `#lead-form` или ведёт на `/zapros-kp/`.
