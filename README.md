# ГК Металлинвест — новый сайт (P1)

Статический фронтенд на [Astro](https://astro.build): главная, хабы каталога, услуги, контакты, доставка, запрос КП, карта 301 и документация в `docs/`.

## Команды

```bash
npm install
npm run dev
npm run build
npm run preview
```

## Документация

- `docs/seo/legacy-crawl-report.md` — краулинг старого сайта
- `docs/seo/redirects-301.csv` — соответствия для редиректов
- `docs/WIREFRAMES.md` — wireframes
- `docs/UI_KIT_FIGMA_HANDOFF.md` — токены и компоненты для Figma
- `public/_redirects`, `vercel.json` — примеры конфигурации 301 на хостинге
